   Carrito de la compra escalabl +
         combina caché rápida L1 LRU en memoria (in-memory-cart-repository.ts) con almacenamiento transaccional L2
         SQLite WAL (sqlite-cart-repository.ts), invalidando automáticamente L1 ante conflictos detectados en L2.
       - Control de Concurrencia Optimista (CAS / ETag + If-Match): validación atómica WHERE id = ? AND version = ?,
         serialización asíncrona ligera por cartId intra-nodo y reintentos con jitter entre nodos (src/application/
         cart-service.ts).
       - Idempotencia (Idempotency-Key): deduplicación Singleflight de peticiones en vuelo y verificación de huella
         SHA-256 del cuerpo (src/infrastructure/idempotency/in-memory-idempotency-store.ts).
       - Checkout con Saga y compensación de stock: revalidación de precios vigentes en catálogo, reserva atómica de
         inventario con TTL y liberación compensatoria automática si la confirmación falla (src/infrastructure/
         catalog/in-memory-catalog-inventory.ts).

     - API HTTP REST + Consola Web Interactiva (src/interfaces/http/ y src/server.ts):
       - Endpoints REST completos (/api/v1/carts, /items, /coupons, /merge, /checkout, /api/v1/products, /api/v1/
         events, /health).
       - Interfaz web interactiva servida directamente en GET / para probar el catálogo, cupones, fusión de usuario y
         checkout desde el navegador.

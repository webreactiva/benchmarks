# Benchmark de modelos (Web Reactiva)

Resultados y proceso completo (prompts, rúbricas, lanzadores, juez y sesiones) de un benchmark de modelos con prompts propios.

- Las reglas están en `README.md` y las rúbricas en `rubricas.md`. No se cambian sin que lo pida el autor.
- Para lanzar, validar o juzgar una prueba se usa la skill `/benchmark-modelos`.
- Los lanzadores necesitan Linux con root (`unshare`); en macOS solo se puede consultar y juzgar.
- Las claves van como variables de entorno, nunca en el repositorio.
